# Vehicle Orders Dashboard

Interactive Power BI dashboard analyzing vehicle orders, sales trends, and customer insights.

![Vehicle Orders Dashboard](Vehicle%20Orders%20Dashboard.png)

![Vehicle Order Dashboard](Vehicle%20Order%20Dashboard.png)

## Project Overview

This project analyzes vehicle order data using Power BI to understand sales performance and order patterns.

## Key Insights

- Total orders and revenue overview
- Sales trends over time
- Performance by vehicle type / category
- Customer and order status analysis

## Tools Used

- Power BI
- DAX
- Data Modeling and Visualization
